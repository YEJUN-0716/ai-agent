# 노션 살림 대시보드 (가계부 + 일정)

## 목표

노션 안에 페이지 1개 + 데이터베이스 2개를 만들어, 달력으로 보고 노션 앱에서
직접 입력한다. 가계부는 **월별 총지출과 카테고리별 합계**가 한 화면에 나온다.

화면도 노션, 입력도 노션이다. 이 저장소의 코드는 관여하지 않는다.

## 준비

claude.ai 커넥터 설정에서 **Notion 연결**을 켠다. 켠 뒤 노션에서 상위 페이지
하나(`살림`)를 만들고 그 페이지를 커넥터에 공유한다. 노션 API는 "어느 페이지
밑에" 만들지를 반드시 요구하므로, 이 한 페이지는 사람이 만들어야 한다.

## 만드는 것

### 상위 페이지: `💰 살림`

두 데이터베이스의 달력 뷰를 나란히 놓는 껍데기.

### ① 가계부 DB

| 속성 | 타입 | 값 |
|---|---|---|
| 항목 | 제목 | |
| 날짜 | 날짜 | |
| 금액 | 숫자 | 원(₩) 표시 |
| 분류 | 선택 | 식비 / 교통 / 주거 / 생활 / 문화 / 의료 / 기타 |
| 구분 | 선택 | 지출 / 수입 |
| 월 | 수식 | `formatDate(prop("날짜"), "YYYY-MM")` |
| 메모 | 텍스트 | |

**「월」 수식이 이 설계의 핵심이다.** 이게 없으면 월별 집계를 볼 때마다 날짜
필터를 손으로 고쳐야 한다. 있으면 그룹만 걸어두고 영원히 방치할 수 있다.

뷰 3개:

| 뷰 | 종류 | 설정 |
|---|---|---|
| 달력 | 캘린더 | 날짜 기준. "언제 썼나"만 본다 |
| 이번 달 | 표 | 필터 `구분=지출` + `날짜 = This month` / 그룹 `분류` / 금액 열 하단 `Sum` |
| 월별 추이 | 표 | 그룹 `월` / 금액 열 하단 `Sum` |

> 노션 **캘린더 뷰는 합계를 못 띄운다.** 그래서 달력과 집계는 뷰를 나눈다.
> 이걸 모르고 "달력에 이번 달 총액을 띄워줘"를 시도하면 시간을 버린다.

### ② 할일 DB

| 속성 | 타입 | 값 |
|---|---|---|
| 제목 | 제목 | |
| 날짜 | 날짜 | 시작~종료(범위 허용) |
| 상태 | 선택 | 할일 / 진행 / 완료 |
| 우선순위 | 선택 | 높음 / 보통 / 낮음 |
| 메모 | 텍스트 | |

뷰 2개:

| 뷰 | 종류 | 설정 |
|---|---|---|
| 달력 | 캘린더 | 날짜 기준 |
| 오늘 | 표 | 필터 `날짜 ≤ Today` **AND** `상태 ≠ 완료` / 정렬 우선순위 내림차순 |

## 손으로 만드는 순서 (커넥터 없이)

15분. 노션 웹/앱에서:

1. 새 페이지 → 제목 `💰 살림`
2. 본문에 `/표 데이터베이스` → 이름 `가계부` → 위 표대로 속성 추가
   - 「월」은 `+` → 유형 **수식** → `formatDate(prop("날짜"), "YYYY-MM")` 붙여넣기
3. 데이터베이스 좌상단 뷰 이름 옆 `+` → **캘린더** → 이름 `달력`
4. 다시 `+` → **표** → 이름 `이번 달` → 필터·그룹·Sum을 위 표대로
5. 같은 식으로 `월별 추이`
6. 2~5를 `할일`로 반복

## 주의

- **노션 API는 뷰를 못 만든다.** 커넥터로 자동 생성해도 데이터베이스와 속성까지고,
  달력·그룹·합계 뷰 5개는 사람이 클릭해야 한다. (위 3~5번)
- 「금액」을 텍스트로 만들면 합계가 안 나온다. 반드시 숫자.
- 「구분」에 수입을 섞어두고 `이번 달` 뷰에서 `구분=지출` 필터를 빼면 총지출이
  수입만큼 부풀어 오른다.
