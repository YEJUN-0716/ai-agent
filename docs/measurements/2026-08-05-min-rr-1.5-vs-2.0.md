# 손익비 기준 1.5 vs 2.0 — 무엇을 잃고 무엇을 얻나 (2026-08-05)

## 왜 쟀나

"손익비 1:2 아래는 추천하지 말라"는 지시(2026-08-05)에 따라 `DEFAULT_MIN_RR` 을
1.5 → 2.0 으로 올렸다. 문턱을 올리면 셋업이 줄어드는 건 자명하고, 남은 셋업의
질이 오르는지가 재 볼 값이다.

## 방법

- 유니버스: 저장 패널 `data/price_panel_v1.parquet` 276종목, 각 종목 최근 400봉
- 시뮬레이션: `modules.trade_plan_backtest.backtest_trade_plans`, fill≤15봉 ·
  hold≤30봉 · 같은 봉이면 손절 우선(보수적)
- **같은 패널·같은 구간에서 기준만 바꿔 두 번** 돌렸다. 서로 다른 날의 기록을
  비교하면 기준 차이인지 장세 차이인지 알 수 없다.

재현:

```
python scripts/measure_trade_plan.py 400 "" 1.5
python scripts/measure_trade_plan.py 400 "" 2.0
```

## 읽는 법

문턱을 올렸더니 **기대값이 떨어졌다.** 잘라낸 구간(R 1.5~2.0)의 셋업 약 600개는
평균 +0.70R 로, 남긴 셋업(+0.36R)보다 두 배 가까이 좋았다.

이유는 승률 줄에 있다: 27.5% → 22.0%. 이 시스템에서 명목 손익비가 크다는 건
"좋은 자리"가 아니라 **목표가 멀다**는 뜻이고, 목표는 멀수록 안 맞는다. R:R 은
잴 때 이미 목표 거리로 계산된 값이라, 그걸 다시 품질 필터로 쓰면 같은 정보를
두 번 세는 셈이 된다.

*단서*: 쿨다운(셋업 종료 후 건너뛰기) 때문에 두 실행의 셋업 집합이 정확한
포함관계는 아니다. 600개 평균 +0.70R 은 차분에서 역산한 근사치고, 방향과
크기는 뒤집히지 않는다.

## 결정

**2.0 채택**(2026-08-05 지시). 위 숫자를 보고받은 뒤의 결정이다 — 측정상 셋업당
기대값은 내려가지만, 추천으로 내보내는 계획의 손익비 하한을 1:2 로 두겠다는
판단이 우선한다.

되돌릴 때 볼 것: `modules/trade_plan.py` 의 `DEFAULT_MIN_RR` 한 곳만 바꾸면
화면 카드·ICT 패널·텔레그램 신호가 함께 따라온다.
