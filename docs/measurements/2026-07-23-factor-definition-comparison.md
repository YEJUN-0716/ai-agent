# 팩터 정의 비교 실측 — 기존 IC 정의 vs 프로덕션 정의

**측정일** 2026-07-23
**도구** `scripts/compare_factor_definitions.py 5` (`factor_validator.run_factor_definition_comparison`)
**이중화 해소 2단계** — 1단계는 PR #21

## 왜 쟀나

IC 파이프라인(`factor_validator`)은 64/22봉 단순수익률·21봉 변동성으로 예측력을
재 왔고, 프로덕션 스캔(`factor_scoring`)은 12-1 모멘텀(252→21봉)·252봉 변동성으로
랭킹한다. PR #19 가 IC 를 실전에 연결한 뒤로 **프로덕션이 쓰지 않는 팩터의
예측력으로 프로덕션 가중치를 배분**해 왔다.

어느 정의가 옳은지는 실측 없이 정할 수 없다. 다만 IC 추정은 재실행만으로도
크게 흔들리므로(같은 조건 재실행에서 quality IC 가 0.0148 → 0.0111, 25% 이동)
**두 정의를 따로 돌려 평균을 비교하면 안 된다.** 여기서는 같은 실행·같은
리밸런싱 날짜·같은 종목 단면 위에서 두 정의를 나란히 재고, 시점별 IC 차이
`d_i = IC_prod,i − IC_legacy,i` 로 짝지어(paired) 판정했다.

## 측정 조건

| 항목 | 값 |
|---|---|
| 유니버스 | 276/276종목 (`modules.universe.SP500`) |
| lookback | 5년 |
| 측정 구간 | 2021-07-26 ~ 2026-06-02 |
| 리밸런싱 | 59회 (rebal=21봉, forward=21봉) |
| EDGAR 커버리지 | revenue 97% / operating_income 80% / net_income 99% / OCF 100% / capex 78% |

프로덕션 정의는 종목당 253봉이 필요해 워밍업을 lookback 창 앞쪽에서 따로
내려받았다. 그래서 여기의 legacy IC 는 저장된 `ic_weights.json` 히스토리와
같은 단면이 아니다 — **이 실행 안의 짝지은 차이만 유효하다.**

## 결과

### 모멘텀 (64봉 단순수익률 vs 12-1 모멘텀)

| | mean_IC | SE |
|---|---|---|
| 기존 IC 정의 | −0.0116 | 0.0185 |
| 프로덕션 정의 | **+0.0240** | 0.0247 |

짝지은 차이: mean **+0.0356**, SE 0.0225, **t = +1.578**, n=59, 프로덕션이 이긴 시점 62.7%

### 변동성 (21봉 vs 252봉)

| | mean_IC | SE |
|---|---|---|
| 기존 IC 정의 | −0.0259 | 0.0296 |
| 프로덕션 정의 | −0.0207 | 0.0336 |

짝지은 차이: mean +0.0052, SE 0.0121, **t = +0.430**, n=59, 프로덕션이 이긴 시점 49.2%

## 판정

**두 항목 모두 구분 불가 (|t| < 2.0).** 정의를 통합할 근거가 아직 없다.
지금 구간을 합치면 근거 없이 프로덕션 랭킹을 바꾸는 것이고, 저장된 IC
히스토리와의 비교도 끊긴다. **3단계는 보류한다.**

읽을 때 주의할 것:

- 개별 `mean_IC` 가 SE 안에 묻히는 것은 정상이다. 판정은 t 로 한다.
  이 유니버스·기간에서 IC 추정의 SE 는 0.02~0.03 수준이고 IC 자체가
  같은 크기다. `mean_IC` 숫자 하나를 근거로 어떤 결론도 내지 말 것.
- 모멘텀은 부호가 갈렸다 — 기존 정의 −0.0116, 프로덕션 정의 +0.0240.
  유의하지는 않지만 **주간 가중치가 프로덕션이 쓰지 않는(그리고 이 기간
  음(−)으로 측정된) 팩터를 근거로 모멘텀 비중을 줄여 왔을 가능성**을
  가리킨다. 62.7% 의 시점에서 프로덕션 정의가 앞섰다.
- 변동성은 두 정의 모두 음(−)이다. 이 기간 저변동성 팩터는 어느 구간으로
  재도 예측력이 없었다. 구간 선택 문제가 아니다.

## 다음

판정을 내리려면 표본을 늘려야 한다. 검토할 방향:

1. **기간 확장** — 5년 → 10년. n 이 59 → 약 120 으로 늘면 SE 가 √2 배 줄어
   현재 차이(+0.0356)가 t≈2.2 에 닿는다. 다만 유니버스 생존편향이 커진다.
2. **리밸런싱 격자 이동** — 시작 offset 을 1~20봉 바꿔가며 반복해 격자
   의존성을 분리한다. 재실행 노이즈의 실제 크기를 직접 재는 방법이기도 하다.
3. **모멘텀만 먼저 결론** — 변동성은 두 정의 다 예측력이 없으므로 통합
   여부가 성과에 영향을 주지 않는다. 모멘텀에 표본을 집중하는 편이 낫다.
