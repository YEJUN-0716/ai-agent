# 빗각 세번째 시간 — 절대원칙 8가지

지금까지 배운 내용 요약: **1편** — 빗각은 곧 추세선에서 출발, 매물대(지지/저항) 기능까지 하는 선. **2편** — 작도 원칙은 고고저(고점-고점 연결 시 저점 발생) / 저저고(저점-저점 연결 시 고점 발생).

오늘은 필자가 직접 정립한 **빗각 절대원칙 8가지**를 정리합니다.

**1. 종합적으로 보기 (일목, 거래량 등)**
빗각 하나만 보지 말 것. 빗각은 결국 변곡점을 잇는 선이므로, 유의미한 지점을 이으려면 거래량 등을 함께 보며 작도할 것.

**2. 장기 빗각 채널 작도**
이후 단기 빗각이 나오면 함께 작도. 채널 개념은 다음 편에서 자세히 설명 예정.

**3. 메이저 코인일수록 장기 빗각 "채널" 위주 대응**
채널 = 빗각을 위아래로 연장한 것. 빗각을 연습하는 이유도 결국 채널 작도를 위함.

**4. 봉마감이 매우 중요 (특히 일봉·주봉마감)**
빗각 위에서 안착 시 대부분 롱 진입. 본인만의 지지 캔들 타임프레임을 정할 것 — 필자는 4H 이상 타임프레임 캔들이 위에서 지지될 때 진입하고 손절가·익절가를 세팅.

**5. 크립토는 나스닥보다 오버슈팅·언더슈팅(페이크 무빙)이 많음**
특히 시가총액 3,000억 미만 잡알트일수록 심함. 매매 시 유의.

**6. 가장 중요한 건 변곡점(추세가 바뀌는 지점)**
변곡점 상세 설명은 다음 편에서. 우선 개념만 숙지.

**7. 빗각 작도가 어려우면 수평 매물대부터 찾기**
특히 잡알트·잡주는 진폭이 커서 차트가 지저분함. 이럴 땐 수평 매물대를 먼저 체크하고 그에 맞춰 빗각을 작도하면 유의미한 결과가 나올 수 있음.

**8. 조정폭 35~40% 이상 = 단기 추세 변곡점으로 보고 채널 작도 가능**
기존 인플루언서들이 정립하지 못한 필자만의 원칙. 채널 작도 시 매우 유용.
