# 빗각 — 결정 시각을 15:50 에서 앞으로 당기면 거짓 진입이 얼마가 되나 (2026-09-06)

실행: `set -a && . ./.env && set +a && python scripts/measure_bitgak_close_gap.py delay`
자료: Alpaca IEX 1분봉 814일 · 표본·시드·여유 분포는 **7단계 그대로**(시드 20260905, 1,000 종목-일)

## 0. 왜 쟀나 — 잰 적 없는 제약이 러너에 걸려 있었다

무료(Basic) 플랜의 sip 은 **최근 15분을 안 준다**. `modules/alpaca_data` 머리말이
이미 적어 둔 제약인데, `run_bitgak_paper.daily_bars` 가 `end=now` 로 박혀 있어
15:30~15:50 ET 창에서 부르면 **항상 403** 이다.

    end = now − 14분  →  403 Forbidden
    end = now − 16분  →  OK

장부(`data/bitgak_paper_ledger.jsonl`)에 `clean` 한 줄뿐이라 `plan()` 은 아직
라이브로 돈 적이 없다. 2026-09-05 의 인증 검증은 `/v2/calendar`(트레이딩 API)만
때렸고 **데이터 API 를 안 밟았다** — 8단계 첫 회차(2026-09-08)에서 터질 자리였다.

물러설 곳이 셋인데 둘이 막혀 있다:

| 길 | 상태 |
|---|---|
| 다음날 시가 진입 (참고 F) | **죽음** — 7단계 §4, ② 하한 −0.000 |
| iex 로 우회 | **불가** — AAPL 거래량 sip 39.8M vs iex 1.22M(3%). ADV \$5M 컷이 다른 컷이 된다 |
| **결정 시각을 지연 밖으로 물린다** | 열림 — 이 문서가 재는 것 |

## 1. 자 검사 — 15:50 행이 7단계를 재현하는가

**자는 안 바꾸고 자리만 옮겼다.** 종가 다리는 모든 cut 이 똑같이 `[15:40, 16:00]`
의 마지막 IEX 프린트를 쓰고, cut 다리만 `[cut−10분, cut]` 으로 움직인다. 종가
다리를 cut 따라 움직이면 재는 게 "막판 이동"이 아니라 **두 창의 차이**가 된다.

| | 7단계 (2026-09-05) | 이번 재실행 |
|---|---|---|
| δ 중위 | 14.9bp | **14.9bp** |
| δ 90분위 | 43.8bp | **43.8bp** |
| 표본 | 683/1,000 | **683/1,000** |
| 거짓 진입 | 11.1% | **11.1%** |
| 참고 2020-08~ | 10.6% | **10.6%** |

**네 자리 다 재현.** 나머지 행을 믿을 근거가 이것이다.

## 2. 결과

여유 중위 84.8bp · 발동 94,310건 (7단계 판정 행)

| cut | 표본 | δ 중위 | δ 90분위 | 거짓 진입 | 2020-08~ | §7.2 갈래 |
|---|---|---|---|---|---|---|
| **15:50** (현 판정선) | 683/1000 | 14.9bp | 43.8bp | **11.1%** | 10.6% | 유지 + 참고 F 대조 |
| 15:40 | 676/1000 | 21.2bp | 58.5bp | 15.3% | 14.7% | 유지 + 참고 F 대조 |
| **15:34** (지연 밖 최선) | 667/1000 | 22.5bp | 65.9bp | **16.3%** | 15.6% | 유지 + 참고 F 대조 |
| 15:30 (보수적) | 666/1000 | 22.7bp | 69.9bp | 16.4% | 15.7% | 유지 + 참고 F 대조 |

**네 행 전부 10~25% 구간이다 — 사전 등록 §7.2 는 「판정 그대로」를 시킨다.**

## 3. 읽는 법

**δ 는 창 길이에 비례하지 않는다.** 10분 → 20분에서 14.9 → 21.2bp (1.42배,
랜덤워크 예측 √2=1.41 과 거의 같다). 그런데 20분 → 26분은 21.2 → 22.5bp,
26분 → 30분은 22.5 → 22.7bp 로 **거의 안 움직인다.** 막판 이동은 마지막 10분에
몰려 있고, 그보다 앞으로 더 물러서 봐야 잃을 게 없다는 뜻이다 — 즉 15:34 와
15:30 사이에서 고민할 이유가 없다. **여유를 더 잡아도 공짜다.**

**꼬리는 계속 두꺼워진다.** 중위는 22.5 에서 멈추는데 90분위는 43.8 → 69.9bp 로
계속 커진다. 중위만 보고 "차이 없다"고 읽으면 안 된다 — 판정선이 중위를 쓸 뿐
(사전 등록 §5.4), 실제로 물리는 날은 꼬리에서 나온다.

**둘 다 하한이다.** δ 의 두 끝을 IEX 프린트로 잡으므로 **경매에서 벌어지는
이동을 이 자가 못 본다**(7단계 §9 그대로). 11.1% 도 16.3% 도 하한이고, 둘의
**비교**만 같은 자 위에 있다.

## 4. 판정에 미치는 것 / 안 미치는 것

- **8단계(배관 번인)는 안 건드린다.** 8단계가 묻는 건 "규칙이 센 것과 실제
  주문이 1:1 인가"다. 거짓 진입도 `plan()` 이 세고 그대로 나가므로 ③ 대조는
  그대로 선다. 시각만 밀린다.
- **여유 7.7bp 는 안 움직인다.** 그 값은 ③b 가 정했지 δ 가 정한 게 아니다.
- **비용은 그 다음 단계에서 받는다.** 거짓 진입이 11.1% → 16.3% 면 규칙이 안 센
  트레이드를 **1.47배** 더 사게 된다. 그 트레이드의 기대값은 잰 적이 없다 —
  +0.029R 이 아니라는 것만 안다.
- **그리고 이번에도 물러설 자리가 없다.** 25% 를 넘으면 §7.2 는 참고 F 로
  옮기라고 하는데 참고 F 가 죽었다. 16.3% 는 그 절벽에서 8.7%p 앞이다.

## 5. 그래서

**15:30 결정 / 15:50 MOC 제출.** 15:34 와 성적이 같은데 여유가 4분 더 있고,
`SIP_DELAY_MIN` 이 흔들려도 403 을 안 맞는다.

바꿀 것은 `daily_bars(end=...)` 한 자리와 8단계 사전 등록 §2.2 의 창 문구다.
**규칙(작도·사다리·형태·컷)은 한 줄도 안 바뀐다.**
