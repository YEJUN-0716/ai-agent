사장님 지시: 미국주식 + 크립토 **둘 다**, 자동 작도해서 **자동매매 진입규칙**까지. 채널선은 **12개**.

## 0. 원문 요약

빗각 = 추세선을 미래 지지/저항 예측선으로 쓰는 기법.

1. **변곡점 3종**에 점을 찍는다 — ①역사적 고/저점 ②추세 변곡 ③돌파 변곡(매물대 돌파)
2. 점을 이어 선을 긋고 검증 — 저저고(저점끼리 이으면 사이에 고점) / 고고저
3. 그 선을 **피보나치 채널**로 확장, 가격이 채널선 위에서 **봉마감 안착**하면 롱 + 손절 필수

## 2. 채널선 12개 — 사장님 결정 (2026-09-04)

원문 4강 본문은 "-2부터 6까지 0.5 간격 → 총 12개"라고 쓰는데 산수가 안 맞는다. 스크린샷(`ep4_img2.png`) 실제 체크는 **-2 ~ 5.5 = 16개**이고, 그중 **양수 쪽 0 ~ 5.5 가 정확히 12개**다.

**채택: k ∈ {0, 0.5, 1.0, … , 5.5} — 12개.** 음수 4선(-2 ~ -0.5)은 쓰지 않는다.

> **결과 하나:** level 0 아래에 선이 없으므로, level 0 진입 시 손절선을 걸 자리가 없다. → **level 0 진입은 받지 않는다.** 진입 가능 레벨은 0.5 ~ 5.5 (11개).

## 3. 기계화 명세

### 3.1 피보나치 채널 (수학 — 임의성 0)

3점 `P1(x1,y1) → P2(x2,y2) → P3(x3,y3)`:

```
slope  = (y2 - y1) / (x2 - x1)
base(x)= y1 + slope * (x - x1)              # level 0
offset = y3 - base(x3)                       # level 1 폭
level_k(x) = base(x) + k * offset
k ∈ {0, 0.5, 1.0, ..., 5.0, 5.5}             # 12개
```

x는 **봉 인덱스**(달력일 아님) — TradingView 기본과 일치시킬 것.

### 3.2 변곡점 후보

`ict_analysis.find_swing_points(df, lookback=L)` 재사용. 새로 만들지 않는다. → **자유도 A**

### 3.3 변곡점 3종 판정

| 종류 | 원문 정의 | 기계화 | 자유도 |
|---|---|---|---|
| ① 역사적 고/저점 | "이전 차트에서 가장 높은/낮은" | 룩백 구간 내 최대/최소 스윙 | 없음 |
| ② 추세 변곡 | "추세가 바뀌는 지점" | 스윙 이후 반대방향 **≥35%** 이동 | **원문 유일 숫자 (3강 8원칙)** |
| ③ 돌파 변곡 | "매물대를 돌파하는 자리" | **볼륨프로파일 최대 구간 돌파** | **자유도 B — 확정** |

**매물대 = 볼륨프로파일.** 가격대별 거래량 히스토그램(일봉 OHLCV 근사)에서 가장 두꺼운 구간을 매물대로 보고, 종가가 그 구간을 위로 벗어나는 봉을 돌파변곡으로 인정한다. 7강의 정의 *"사람들의 평균 단가가 특히 몰려있는 자리"* 와 글자 그대로 일치한다.

9강의 *"거래량과 상관없이 변곡자리에 점을 찍는다"* 는 **거래량 터진 봉 하나를 쫓지 말라**는 뜻이지 매물대를 계산하지 말라는 뜻이 아니다 — 매물대는 개념 자체가 거래량이고, 3강 7원칙도 *"작도가 어려우면 수평 매물대부터 찾으라"* 고 한다. 초안에서 스윙고점 클러스터(거래량 미사용)를 1안으로 뒀던 것은 이 오독 때문이었고, 2026-09-04 사장님 결정으로 볼륨프로파일로 확정했다.

### 3.4 저저고/고고저 검증 — 자유도 아님

베이스라인이 저점-저점이면 x1~x2 **사이에 스윙 고점이 존재**하면 인정. 별도 % 문턱을 두지 않는다.

이유: 두 저점을 이은 선 위로 반등이 있으면 거의 항상 선 위에 있으므로, % 문턱은 사실상 아무것도 걸러내지 않는다. 실제 엄격함은 **L(스윙 민감도)**이 정한다. 파라미터를 하나 더 만들지 않고 A에 흡수시킨다.

### 3.5 진입 규칙 — 진입 레벨도 자유도 아님

11강 *"현재 2채널 위에서 지지"* → 저자는 특정 레벨을 고르지 않는다. **가격이 지금 닿아 있는 선**에서 대응한다. 그대로 기계화한다.

| 항목 | 원문 | 우리 규칙 |
|---|---|---|
| 타임프레임 | 4H 이상 | **일봉** (기존 인프라. 미국주식엔 4H 없음) |
| 진입 | 채널선 위 봉마감 안착 | 종가 > level_k **이고** 직전봉 종가 ≤ level_k, k ∈ 0.5~5.5 |
| 손절 | "반드시 세팅" (수치 없음) | **한 칸 아래 선** level_{k-0.5} → **자유도 C** |
| 익절 | 없음 | 한 칸 위 선 level_{k+0.5} (8강 "한 칸만큼 급등") |
| 포지션 | — | 종목당 1개. 이미 보유 중이면 새 진입 무시 |

손절이 한 칸 아래 선이므로 **R = 채널 한 칸 폭**. 트레이드 기하학과 같은 자로 잴 수 있다.

### 3.6 유니버스

- **미국주식** — 기존 대형주 패널
- **크립토** — yfinance `BTC-USD`/`ETH-USD` 등 **일봉**. ccxt/Binance 불필요
- 원문 3강 5원칙이 *"크립토는 나스닥보다 오버슈팅·페이크무빙이 많다"* → **합쳐서 재지 말고 따로 잰다**

## 4. 진짜 자유도 — 3개, 전부 봉인 (2026-09-04 사장님 결정)

| | 이름 | **확정값** | 원문 근거 | 틀렸을 때 |
|---|---|---|---|---|
| **A** | 스윙 민감도 L | **5** | 없음 (저장소 관행) | 후보 점이 통째로 바뀌고 → 채널이 바뀌고 → 발동 횟수가 바뀐다. 발동 횟수가 검출력을 정하므로 A는 "잴 수 있느냐"를 좌우한다 |
| **B** | 돌파변곡(매물대) | **볼륨프로파일 최대 구간 돌파** | 7강 정의와 일치 | 3점 중 1점이 어긋나면 채널 전체가 어긋난다 |
| **C** | 손절 | **한 칸 아래 선** level_{k-0.5} | 없음 (채널 논리) | R 정의가 바뀌어 성과 수치가 전부 바뀐다 |

추가 확정: **level 0 진입은 받지 않는다** (음수 선을 쓰지 않으므로 손절 걸 자리가 없다). 진입 가능 레벨 0.5 ~ 5.5.

**A와 C는 원문에 없는 값이다.** 원문에 있는 숫자는 ②추세변곡의 35% 하나뿐.

10강에서 저자 본인이 *"융통성 있게 작도해야 하는 상황이 꽤 많다 — 이론의 한계"* 라고 쓴다. 이 자유도를 열어두면 "졌으면 잘못 그린 것"으로 빠져 판정 자체가 불가능해진다. **A/B/C 는 여기서 봉인한다. 2단계 이후 그리드 서치·재조정 금지** — 바꾸려면 새 사전 등록으로 간다.

**미확정으로 남긴 것 하나:** 채널 한 칸 폭이 종목마다 다르므로(BTC 주봉 20% vs 어떤 주식 3%) 실제 사이징 규칙이 종목마다 달라진다. R 단위 측정에는 지장 없다. 정찰 통과 후에 정한다.
